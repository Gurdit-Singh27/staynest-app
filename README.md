# StayNest 🏡

A full-stack Airbnb-like listing platform where users can browse, create and review stays.

## Planned Features

- Create, edit and delete property listings
- Image uploads with Cloudinary
- User authentication (signup / login)
- Reviews and ratings
- Map integration
- Responsive UI

## Tech Stack

- Node.js, Express.js
- MongoDB, Mongoose
- EJS, ejs-mate
- Passport.js
- Cloudinary

## Status

🚧 In active development.
